# 知识图表工坊

把一段知识浓缩成一张好读、好看的图。使用者对美感要求很高，也给过很具体的意见，下面的铁律都来自这些意见，不要自行放宽。

## 铁律（使用者亲自定下的）

1. **字要大**：手机上文字不低于 15px。图上任何说明字都不能小到要放大才看得清。
2. **字要少**：每个节点或标签不超过 6 个字，说明不超过 14 个字，一张图只留一句结论（takeaway）。宁可拆成两张图，也不要塞满。
3. **要成熟、专业、有艺术感**：不要卡通大头小人、对话泡泡、黄色可爱角色。
4. **心智图每个分支都有外框，外框颜色各不相同**，子节点沿用同一色系，一眼分出分支。
5. **默认简体中文**。书名或原文引用可保留原字。
6. **中文字百分之百正确**：AI 画的图不带字，所有文字都由程序排上去。
7. **只用两套自有配色**：莫兰迪知性（`mo`，预设）、灵境晶光（`ling`）。不沿用参考图的配色。
8. **所有图表固定 16:9**：引擎在 1280×720 的舞台上排版、整张等比缩放，空间要用满；手机上靠「⤢ 放大」全屏检视。不要为了手机改成直式。

## 作业流程

### 1. 浓缩内容
读完来源内容（Notion 书摘、使用者贴的文字、档案），先想清楚「这张图要让人记住哪一句话」，写成 takeaway。再挑出 3–8 个重点，每个压到 6 字内。只用来源里有的资讯，不编造。

### 2. 选图表类型
看内容的结构来选，细节、资料格式与字数上限见 `references/charts.md`：

| 内容长这样 | 用 |
|---|---|
| 一本书／一章的整体架构 | `mindmap` 框线心智图 |
| 三个要素一起才成立；或一个核心带 4–6 个面向 | `logic` 立体圆球逻辑图 |
| 有先后的因果链、步骤 | `flow` 箭头流程 |
| 会绕回起点的恶性／良性循环 | `cycle` 循环图 |
| 两个概念对照 | `compare` 左右对比 |
| 依时间发展 | `timeline` 时间轴 |
| 两个维度交叉出四种情况 | `matrix` 四象限 |
| 有高低层次 | `pyramid` 金字塔 |
| 几个平行的方法、建议 | `cards` 重点卡片 |
| 一个中心向外放射的清单 | `radial` 放射图 |
| 需要情境、人物、情绪姿态 | `illus` 手绘插画＋标签（见 `references/illustration.md`） |

使用者没指定、内容又适合两种以上时，挑最贴切的一种直接做，回覆时一句话提另一种选择。

### 3. 选配色
- `mo` 莫兰迪知性：心理学、情绪、讲义、知识整理（预设）
- `ling` 灵境晶光：身心灵、冥想、佛道经典、灵性主题

### 4. 写 JSON、自检、出图
1. 照 `references/charts.md` 写 spec JSON（`examples/` 有每种类型的范例，可直接复制改写）。
2. 执行 `python3 scripts/check.py spec.json`，有「错误」就改到通过；「提醒」斟酌处理。
3. 出图：`python3 scripts/render.py spec.json -o out.html --png out.png`（固定 16:9，PNG 为 2560×1440）。
   - 没有 Python 或浏览器的环境（例如 claude.ai 一般对话）：把 `assets/template.html` 的 `__ENGINE__` 换成 `assets/engine.js` 全文、`__SPEC__` 换成 JSON，直接当 Artifact 发布。
4. 能截图就看一眼成品：文字有没有重叠、出界、太小。有问题修一次再交付。

### 5. 交付
依使用者要放的地方处理，详见 `references/delivery.md`：
- 网页／App 里看 → Artifact（会自动在手机改成直式）
- Notion → 高清 PNG＋文字版（图无法上传时，至少放文字版与 mermaid 心智图）
- 讲义、简报 → 横式 PNG
- 「我的书房」App → spec JSON 存进研读心得的「图表数据」栏位

交付时用一两句话说明用了哪种图、哪套配色；有做不到的（例如 PNG 没产生）要直说原因。

## 手绘插画

需要人物、情绪姿态、情境时才画插画，纯结构性的内容用前面的图表就好。画法、参考图编号与完整提示词范本在 `references/illustration.md`。重点：
- 用 Higgsfield 的 GPT Image 2.5，quality `xhigh`、resolution `2k`，带上使用者的画风参考图。
- 画风是「干净针笔线、每笔一次画完、无排线无阴影、平涂色、多留白」。使用者否决过：数位光滑感、线条太粗、像铅笔画的排线。
- 图里**不放任何文字**，留空白标签框，由 `illus` 类型把中文标签排上去。
- 每张约消耗少量点数，一次画 1–2 张，请使用者挑，不要一次大量生成。

## 档案地图
- `references/charts.md`：11 种图表的用途、JSON 栏位、字数上限
- `references/palettes.md`：两套配色色票与使用时机
- `references/illustration.md`：手绘插画的模型设定、提示词范本、合成文字的方法
- `references/illustration-refs.md`：使用者上传的 16 张画风参考图编号
- `references/delivery.md`：Artifact、PNG、Notion、「我的书房」App 的交付方式
- `assets/engine.js`：出图引擎（浏览器端，不依赖任何外部函式库）
- `scripts/render.py`：JSON → HTML（＋PNG）
- `scripts/check.py`：铁律自检
- `examples/`：每种图表的范例 JSON（内容取自《破解情绪密码》）
