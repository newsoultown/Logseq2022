# 自有配色

使用者看过三套配色样张后，选定下面两套（东方雅韵已淘汰）。色票已写死在 `assets/engine.js` 的 `PAL`，JSON 里用 `palette` 指定即可，不要另外调色。

## mo 莫兰迪知性（预设）
温柔、专业、低饱和。适合心理学、情绪、讲义、知识整理。

| 用途 | 色 |
|---|---|
| 底色 | #f2efe9 |
| 纸面 | #fdfbf8 |
| 文字 | #37332f |
| 次要文字 | #6b655e |
| 分支 1–6 | 灰绿 #6f8a78、灰蓝 #6f84a0、陶土粉 #b67f70、燕麦 #a88f68、雾紫 #8d7d9c、青灰 #7f9393 |

## ling 灵境晶光
柔和光感、偏冷的紫蓝。适合身心灵、冥想、佛道经典、灵性主题。

| 用途 | 色 |
|---|---|
| 底色 | #f4f2fa |
| 纸面 | #fdfcff |
| 文字 | #2c2843 |
| 次要文字 | #67628a |
| 分支 1–6 | 淡紫 #7562cf、雾蓝 #4f86c6、珍珠粉 #c4729e、青碧 #3f9e96、藤紫 #9a7fd8、晨金 #d1955a |

## 插画用色
手绘插画只用一到两个点缀色，从同一套配色挑：
- 莫兰迪：灰绿 #7d9584（单色）；或灰绿＋陶土粉
- 灵境：淡紫 #9a8be0＋雾蓝 #6f9bd2
