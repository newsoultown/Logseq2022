# 我的书房

阅读、研读 Notion「书摘参考库」的个人 App（Claude Artifact）。

- 线上版：https://claude.ai/artifact/K6fJRwYJG67DufB5rHtUMb
- 图表样张：https://claude.ai/artifact/K3bPJqngKgUNyyqntqNj5J（chart-specimens.html）
- 图表引擎与 `skills/knowledge-chart-studio/assets/engine.js` 是同一份；改引擎时两边一起更新。

## v0.8（2026-10-03）
- 整体改成书桌版面，取代原本的宅院入口与三个房间：
  - 左边：书架选单（心理／成长／灵性各分类），点一下在中间摆出那一格的书
  - 中间：软木看板，正中钉着「正在阅读」，四周是最近读过的书（最多 8 本）；下方桌面放「我的心得」笔记本与金句卡盒
  - 右边：档案柜＝研读本，每个抽屉一本
- 书脊书名去掉标点、括号等符号；书架上的书缩小（电脑 72%、手机 56%），字级 16／13px，书名超过 12 字截断
- 所有图表固定 16:9（1280×720 舞台整张缩放），右下角「⤢ 放大」全屏检视

## v0.7（2026-10-03）
- 图表改用知识图表工坊引擎：11 种图表、莫兰迪知性／灵境晶光配色
- 简繁切换（Aa 面板：简体／繁体／照原文），只改显示，不动 Notion 原文
- 心得与图表同时写进「研读心得」数据库与书摘页面末尾的「我的研读笔记」区
- 书摘原文可编辑：写回 Notion 页面，旧文字存成「原文修改」记录
